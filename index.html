Dependencias MySQL + Hibernate (pom.xml)

Bloque estándar para conectar un proyecto Maven a MySQL 8 con Hibernate 6.

pom.xml XML 
<dependencies>
    <dependency>
        <groupId>com.mysql</groupId>
        <artifactId>mysql-connector-j</artifactId>
        <version>8.3.0</version>
    </dependency>
    <dependency>
        <groupId>org.hibernate.orm</groupId>
        <artifactId>hibernate-core</artifactId>
        <version>6.4.4.Final</version>
    </dependency>
</dependencies>

Sistemas • Terminal

Liberar puerto 8080 / 3306 bloqueado

Cuando Tomcat, Spring o MySQL dicen que el puerto ya está en uso y no arrancan.

CMD / Bash Shell 
# Windows (CMD Admin):
netstat -ano | findstr :8080
taskkill /PID <PID> /F

# Linux / macOS:
sudo lsof -i :8080
kill -9 <PID>
PROG • Git

Deshacer último commit sin perder cambios

Vuelve al estado anterior al commit dejando tu código intacto en el editor.

Terminal Git Git 
# Deshacer commit manteniendo código:
git reset --soft HEAD~1

# Borrar carpeta target/ subida por error:
git rm -r --cached target/
git commit -m "fix: quitar target"
PSP • Concurrencia

Diferencia rápida: Thread vs Runnable

En Java solo hay herencia simple: implementa Runnable si tu clase ya hereda de otra.

HiloEjemplo.java Java 
Runnable tarea = () -> {
    System.out.println("Hilo: " + Thread.currentThread().getName());
};
Thread hilo = new Thread(tarea);
hilo.start(); // ¡Nunca llames a run() directo!
DI & Web • JS Fetch

Petición fetch() con async / await

Plantilla limpia para consumir cualquier API REST en JavaScript.

api.js JavaScript 
async function obtenerDatos(url) {
    const res = await fetch(url);
    if (!res.ok) throw new Error("Error HTTP: " + res.status);
    return await res.json();
}
