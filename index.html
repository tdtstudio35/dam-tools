// Copy-Paste de Supervivencia

Cosas que siempre acabas buscando en Google a mitad de una práctica. Haz clic en copiar.

1. Dependencia Maven MySQL + Hibernate (pom.xml) 
<dependencies>
    <!-- Conector MySQL 8 -->
    <dependency>
        <groupId>com.mysql</groupId>
        <artifactId>mysql-connector-j</artifactId>
        <version>8.3.0</version>
    </dependency>
    <!-- Hibernate Core -->
    <dependency>
        <groupId>org.hibernate.orm</groupId>
        <artifactId>hibernate-core</artifactId>
        <version>6.4.4.Final</version>
    </dependency>
</dependencies>
2. Conexión JDBC MySQL (Sin error ServerTimezone) 
String url = "jdbc:mysql://localhost:3306/mi_bd?useSSL=false&serverTimezone=UTC&allowPublicKeyRetrieval=true";
String user = "root";
String pass = "";

try (Connection con = DriverManager.getConnection(url, user, pass)) {
    System.out.println("Conectado a la BD con éxito");
} catch (SQLException e) {
    e.printStackTrace();
}
3. Matar puerto 8080 / 3306 cuando se queda pillado 
# En Windows (CMD como Administrador):
netstat -ano | findstr :8080
taskkill /PID <NUMERO_PID> /F

# En Linux / Mac:
sudo lsof -i :8080
kill -9 <NUMERO_PID>
4. Git: Liada parda (Deshacer commit sin borrar código) 
# Deshace el último commit pero mantiene tus cambios intactos:
git reset --soft HEAD~1

# Si subiste la carpeta target/ o .idea/ sin querer:
git rm -r --cached target/
git commit -m "fix: eliminar carpeta target del repo"
